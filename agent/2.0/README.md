# Print Shop Local Agent 2.0

Print Shop Local Agent 2.0 with Windows Desktop Companion window, system tray integration, and startup persistence.

### Commands:
```powershell
npm run gui           # Launch the Desktop Companion GUI
npm start             # Launch Headless CLI Agent
npm run autostart:on  # Register with Windows Startup
npm run autostart:off # Unregister from Windows Startup
npm run nosleep       # Prevent Windows Sleep Mode
```

See `../README.md` for full documentation and architecture details.
